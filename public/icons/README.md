# PravAI reference icon set

21 custom vector recreations made for this app from the supplied design reference.
These are editable SVG interpretations, not original source assets extracted from the screenshot.
Open index.html for a preview and individual downloads.

Each SVG has a transparent background and embedded colors/gradients, with no font,
network, or package dependency. Standard icons use a 64 × 64 viewBox; tutor.svg uses
120 × 120. Render at any size. Circular colored backgrounds belong to the app CSS,
so icons can also be used without badges in native clients.

Files: car, tests, book, brain, target, pin, star, chart, turn, crossroad, warning,
speed, home, checklist, profile, chat, bell, flame, gift, check, tutor.

The app's shared React wrapper is src/components/DesignIcon.tsx.
